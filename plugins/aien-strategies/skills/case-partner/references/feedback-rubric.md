# Grille de débrief — Barème MBB

Note chaque dimension de 1 à 5. La barre pour passer un premier tour MBB : **aucune note sous 3, au moins deux notes à 4+**.

## Méthode de notation (obligatoire, dans cet ordre)

1. **Preuves d'abord.** Avant de rédiger le débrief, relève pour chaque dimension les moments précis du cas (citations exactes du candidat) et coche la checklist de critères ci-dessous. Un critère est coché seulement s'il a été **observé explicitement** pendant le cas — « il l'a probablement fait » = non coché.
2. **Note déduite, jamais ressentie.** La note est le niveau le plus élevé dont toutes les conditions sont remplies, plafonds compris. Si tu hésites entre deux notes, tu n'as pas fini de cocher : retourne aux critères.
3. **Justification par encadrement.** Pour chaque note, annonce : la citation qui prouve le niveau atteint, ET le critère précis qui a manqué pour le niveau supérieur (pour un 5 : ce qui le distingue d'un 4).

## 1. Structuration

Capacité à décomposer le problème en un cadre MECE **adapté au cas** — pas un framework récité.

Critères observables (binaires) :

| # | Critère |
|---|---|
| S1 | A demandé un moment pour structurer avant de répondre |
| S2 | A annoncé sa structure complète avant de plonger dans une branche |
| S3 | Structure MECE : pas de chevauchement, aucun trou majeur par rapport au corrigé |
| S4 | Au moins un élément spécifique au secteur/contexte du cas (pas un framework plaqué) |
| S5 | Priorisation argumentée (« je commence par X parce que... ») |
| S6 | Revient explicitement à sa structure après au moins une analyse |
| S7 | Une branche de la structure pointe vers le twist (à vérifier contre le corrigé) |

| Note | Conditions (toutes requises) |
|---|---|
| 1 | Ni S2 ni S3 : pas de structure réelle, attaque au fil de l'eau |
| 2 | S2 ou S3, mais pas S4 : framework générique plaqué |
| 3 | S2 + S3 + S4 |
| 4 | S2 + S3 + S4 + S5, et au moins un de S1/S6 |
| 5 | Note 4 + S6 + S7 (rare) |

## 2. Rigueur quantitative

Exactitude, rythme, et maîtrise du calcul comme outil.

| # | Critère |
|---|---|
| Q1 | Zéro erreur de calcul non corrigée (une erreur détectée et corrigée seul ne compte pas contre lui) |
| Q2 | Pose la méthode avant de calculer (formule ou approche annoncée) |
| Q3 | Arrondis intelligents, annoncés comme tels |
| Q4 | Sanity check spontané (ordre de grandeur vérifié sans y être invité) |
| Q5 | Rythme tenu : pas de blanc prolongé, aucun calcul fait à sa place |
| Q6 | Enchaîne de lui-même sur le « so what » du chiffre, ou anticipe le calcul utile avant qu'on le demande |

Plafonds (s'appliquent avant le barème) :

- Une erreur maintenue malgré « Vous êtes sûr de ce chiffre ? » → **plafond 2**.
- Plusieurs erreurs non corrigées, ou l'interviewer doit faire le calcul → **note 1**.

| Note | Conditions |
|---|---|
| 1 | Plafond atteint, ou panique bloquante face aux chiffres |
| 2 | Q1, mais pas Q2 : juste mais désordonné, méthode non annoncée |
| 3 | Q1 + Q2 |
| 4 | Q1 + Q2 + Q4, et au moins un de Q3/Q5 |
| 5 | Les six critères cochés |

## 3. Business sense

Capacité à transformer une analyse en insight et à voir le twist du cas.

| # | Critère |
|---|---|
| B1 | Interprétations correctes des données (au besoin après relance) |
| B2 | Hypothèses chiffrées réalistes et justifiées ; aucune hypothèse absurde maintenue |
| B3 | « So what » spontané après chaque analyse majeure — sans « qu'est-ce que ça vous inspire ? » |
| B4 | Relie explicitement au moins deux analyses entre elles |
| B5 | Trouve le twist sans aide (à vérifier contre le corrigé) |
| B6 | Au moins un raisonnement de second ordre (réaction concurrents, faisabilité, risques) |

| Note | Conditions |
|---|---|
| 1 | B1 non coché : n'interprète pas les données, ou interprète faux même relancé |
| 2 | B1, mais pas B2 : conclusions correctes mais hypothèses irréalistes |
| 3 | B1 + B2 : juste, mais réactif — les insights sortent sur sollicitation |
| 4 | B1 + B2 + B3 |
| 5 | B1 + B2 + B3 + B5, et au moins un de B4/B6 (rare) |

## 4. Communication et synthèse

Clarté, concision, et qualité de la synthèse finale.

| # | Critère |
|---|---|
| C1 | Suivable en continu : jamais besoin de faire reformuler pour comprendre |
| C2 | Concis : s'arrête quand le point est fait, pas de digression |
| C3 | Annonces top-down pendant le cas (« trois facteurs : un... deux... trois... ») |
| C4 | La synthèse finale ouvre sur la recommandation (answer first) |
| C5 | Synthèse en ≤ 90 secondes : recommandation → 2-3 arguments chiffrés → risques/next steps |
| C6 | Gère une interruption ou une objection sans perdre le fil (coché seulement si testée pendant le cas) |

| Note | Conditions |
|---|---|
| 1 | C1 non coché : confus, impossible de suivre |
| 2 | C1 seul : compréhensible mais verbeux, ou synthèse chronologique |
| 3 | C1 + C2, mais pas C4 : clair, mais la synthèse part du raisonnement |
| 4 | C1 + C2 + C4 + C5 |
| 5 | Note 4 + C3, et C6 si une interruption a été testée (discours tenable tel quel devant un CEO) |

## Format du débrief (à suivre dans l'ordre)

0. **Préparation silencieuse** : checklists cochées, citations relevées, notes déduites (cf. « Méthode de notation »). Rien de cette étape n'est montré tel quel — elle précède la rédaction.
1. **Verdict global en une phrase** : « Sur cette performance, un premier tour MBB serait [validé / non validé / limite], principalement à cause de [dimension]. »
2. **Tableau des 4 notes** avec, pour chacune : UNE citation précise qui justifie le niveau atteint, ET le critère manquant pour le niveau supérieur.
3. **Forces** (1-2, réelles, avec citation).
4. **Axes prioritaires** (2-3 max), classés par impact, chacun avec : le moment précis où ça a coûté, ce qu'un candidat top aurait fait à la place, et un exercice ciblé.
5. **Le corrigé du twist** : révèle l'insight central du cas et la recommandation attendue, même si le candidat l'a trouvé (pour calibrer).

## Interdits pendant le débrief

- Aucune note « au ressenti » : si une note ne se déduit pas de la checklist, c'est la checklist qui gagne.
- Aucune note de 4+ sans citation textuelle correspondant aux critères cochés.
- Aucun feedback générique (« sois plus structuré ») sans citation d'un moment précis.
- Ne gonfle pas les notes pour faire plaisir : un 3 est une performance correcte, un 4 est bon, un 5 est rare. Sur un vrai premier tour, des 2 sont fréquents — une grille remplie de 3-4 sans citations est un signe de complaisance, pas de niveau.
- Ne donne pas plus de 3 axes d'amélioration : au-delà, rien n'est retenu.
