# Matrice de sélection

Croiser le contexte diagnostiqué (étape 1) avec le plan adéquat. La matrice
oriente ; elle ne dispense pas d'expliquer le POURQUOI à l'utilisateur.

## Matrice contexte → plan

| Combinaison de contexte | Plan recommandé |
|---|---|
| Commercial + Dirigeants + Convaincre | AIDA ou Elevator Pitch (Pain-Solution-Preuve-Ask) |

| Commercial + Clients + Confiance | PAS + preuve sociale |

## Paramètres de contexte (auto-détecter ou demander)

**Type de prise de parole**
- Commercial → AIDA/PAS, accent ROI, différenciation, déclencheurs d'urgence.
- Leadership → Monroe/Vision-Réalité-Changement, inspiration > logique, récits personnels, futur.
- Technique → Problème-Solution-Validation, dense en données, marqueurs de crédibilité.
- Sensible → Empathie-Réalité-Chemin-Soutien, langage diplomatique, reconnaissance d'abord.
- Défaut → rhétorique classique avec une touche moderne.

**Profil d'audience**
- Dirigeants → conclusion d'abord (BLUF), impact stratégique, efficace, orienté décision.
- Équipe → ton collaboratif, appropriation partagée, étapes concrètes, clôture motivante.
- Clients → construction de confiance, preuve sociale, réduction du risque, bénéfices clairs.
- Mixte → strates de complexité, points d'entrée multiples, types de preuve variés.
- Défaut → professionnel mais accessible.

**Niveau de résistance**
- Élevé → partir d'un terrain commun, traitement extensif des objections, dense en preuves, persuasion graduelle.
- Moyen → reconnaître les inquiétudes tôt, équilibrer push/pull, proposer des options.
- Faible → approche directe, focus optimisation, clôture assumée.
- Défaut → supposer un scepticisme modéré.

**Résultat visé**
- Convaincre → logique dominante, cascade de preuves, lever les objections, point de décision clair.
- Inspirer → émotion en avant, peindre la vision, focus possibilités, connexion personnelle.
- Informer → priorité clarté, cadres mémorisables, points d'action pratiques, prêt pour Q&R.
- Conduire le changement → reconnaître la perte, peindre le gain, feuille de route, structure de soutien.
- Défaut → équilibre informer-et-influencer.

**Contexte culturel**
- Haute contextualité → approche indirecte, relation d'abord, harmonie du groupe, respect des hiérarchies.
- Basse contextualité → communication directe, bénéfices individuels, efficacité, métriques claires.
- Mixte → valeurs universelles, éviter les idiomes, raisonnement explicite, support visuel.
- Défaut → standard business occidental avec marqueurs de sensibilité.
