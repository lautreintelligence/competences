# Livrables, transitions, error recovery

## Formats de sortie (étape 6)

**`plan` (défaut)**
- Plan hiérarchique avec un timing par section.
- Notes orateur : phrases-clés, marqueurs d'emphase, suggestions de geste.
- Une phrase de transition entre chaque section.
- 2-3 options d'accroche d'ouverture.
- 2-3 options d'appel à l'action de clôture.

**`script`**
- Texte de prise de parole en langage naturel, ton conversationnel.
- Marqueurs `[EMPHASE]` sur les mots/phrases clés.
- Indications `(Pause)` pour l'effet.
- Notes `{Geste : description}`.

**`slides`**
- Structure slide par slide : titre, message-clé (1 phrase max), suggestion visuelle (type de graphique, image, icône), notes orateur, logique d'animation si pertinente.
- Distribution : 1 idée par slide, max 6 mots par puce.

**`all`**
- Package intégré avec renvois croisés entre plan, script et slides.

## Contraintes de format

- Le contenu tient dans le temps imparti (±10 %).
- Chaque point majeur a une preuve/un exemple d'appui.
- Transitions entre sections < 30 sec.
- Accroche d'ouverture < 1 min ; appel à l'action de clôture < 2 min.
- Suggestions de support visuel alignées sur le verbal.

## Templates de transition

**Accroches d'ouverture** (choisir selon le contexte)
- Question : « Et si [résultat désirable] était possible en [délai] ? »
- Statistique : « [Chiffre choc] des [groupe] font face à [problème]. »
- Histoire : « La dernière fois, [personne identifiable] a vécu exactement ça… »
- Défi : « Tout le monde pense [croyance commune], mais… »
- Objet/visuel : un objet physique ou une image frappante qui incarne le message (cf. l'enveloppe de Steve Jobs pour le MacBook Air).

**Ponts entre sections**
- « Maintenant qu'on comprend [point précédent], explorons… »
- « Cela nous mène à la question cruciale de… »
- « Mais connaître le problème ne suffit pas ; il nous faut… »
- « Vous vous demandez peut-être comment ça s'applique à… »

**Moteurs de clôture**
- Choix binaire : « Le choix est clair : [option A] ou [option B]. »
- Action immédiate : « Dès demain, vous pouvez [action précise]. »
- Vision : « Imaginez dans [horizon] quand [vision atteinte]. »
- Défi : « La seule question qui reste : êtes-vous prêts à… »

## Error recovery

**Information insuffisante** → « Pour choisir la meilleure structure, j'ai besoin de comprendre [élément manquant précis]. Peux-tu me dire… »

**Objectifs contradictoires** → « Je note une tension entre [objectif A] et [objectif B]. Lequel est prioritaire, ou comment veux-tu les équilibrer ? »

**Plan inadapté repéré en cours** → « Vu ton contenu, une structure [plan alternatif] serait plus puissante parce que [raison]. On explore ? »

**Dépassement du temps** → « Ce contenu dépasse ta limite de [X] min. Priorisons : qu'est-ce qui est essentiel vs accessoire ? »

**Plan imposé par l'utilisateur** → utiliser le plan demandé, signaler brièvement une meilleure option seulement si elle existe : « J'utilise [ton choix] comme demandé. Je note juste que [alternative] marcherait bien aussi ici parce que [raison] — je peux basculer si tu veux. »

## Standards qualité (étape 8)

- Complétude : chaque affirmation a une preuve.
- Flux logique : pas de trou ni de saut.
- Tenue temporelle : ±10 % du temps imparti.
- Rythme : ouverture < 1 min, transitions < 30 sec, clôture < 2 min.
- Alignement : la présentation atteint l'objectif déclaré.
- Pertinence culturelle : aucune valeur supposée universelle.
- Éthique : pas de manipulation par fausse information, aucun contre-argument majeur ignoré.
- Message-clé renforcé 3+ fois ; proposition de valeur dans les 2 premières minutes.
