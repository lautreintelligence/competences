# Axe 1 — Plans séquentiels

Un plan séquentiel définit l'ordre des sections d'une prise de parole. Chaque
plan est une séquence prête à remplir. Les principes d'ordonnancement, le dosage
des appels et les leviers de persuasion (axes 2-4) s'appliquent par-dessus
n'importe lequel de ces plans — voir `axes-transverses.md`.

## Famille A — Problème → Solution

**Problème-Solution (5 temps)** — Situation/constat → Proposition → Bénéfices attendus → Anticipation des objections → Appel à l'action.
Usage : adoption d'une mesure, vente d'une idée, plaidoyer interne.

**PAS** — Problème → Agitation (amplifier la douleur) → Solution.
Usage : pitch court, accroche commerciale. Crée un contraste fort avant le remède.

**PASTOR** — Problème → Amplification → Story (récit) → Transformation → Offre → Réponse demandée.
Usage : argumentaire de vente long, page de vente, webinaire.

## Famille B — Pitch / présentation brève

**AIDA** — Attention → Intérêt → Désir → Action.
Usage : publicité, annonce, vente directe. Suit le cheminement psychologique du prospect.

**Elevator Pitch** — Pain (problème) → Solution unique → Preuve (chiffres, client, étude) → Ask (next step précis).
Usage : networking, rendez-vous business, appel d'offres, 30 sec à 2 min.

**FAB** — Features (caractéristiques) → Advantages (avantages) → Benefits (bénéfices client).
Usage : démonstration produit. Traduit le technique en valeur perçue.

**BE MAGNETIC** — Besoin → Expertise → Message → Attention → Gain → Narration → TIC (Transmettre-Impliquer-Conclure).
Usage : elevator pitch structuré quand on veut couvrir crédibilité ET émotion en temps contraint.

## Famille C — Stratégique / dirigeants

**SCR / Pyramide de Minto** — Situation → Complication → Résolution.
Usage : note de décision, présentation au board, demande d'approbation. Conclusion d'abord, preuves ensuite.

**Reality-Options-Recommendation** — État réel sans fard → Options possibles → Recommandation argumentée.
Usage : crise, arbitrage dirigeants. Donne le choix tout en orientant.

**Comparaison-Choix-Décision** — Exposer plusieurs scénarios → Comparer (gains/pertes) → Justifier le choix retenu → Réduire les craintes.
Usage : décision collective, conduite du changement, comité.

## Famille D — Leadership / mobilisation

**Séquence motivée de Monroe** — Attention → Besoin → Satisfaction → Visualisation → Action.
Usage : mobilisation d'équipe, discours de changement. Visualisation = faire vivre le futur désirable.

**Triangle rhétorique séquencé** — voir `axes-transverses.md` (Ethos-Pathos-Logos est un dosage, pas un ordre figé, mais peut servir de plan : crédibilité → connexion → arguments).

**Chronologique** — Passé (état initial) → Présent (le basculement) → Futur (ce que cela permet). Variante : Before → Transformation → After.
Usage : exposer une transformation, une évolution, une vision.

## Famille E — Situations sensibles

**Empathy-Context-Decision-Support** — Empathie/reconnaissance → Contexte factuel → Décision → Soutien/accompagnement.
Usage : annonce difficile à une équipe, mauvaise nouvelle. Reconnaître avant d'annoncer.

**Acknowledge Loss → Paint Gain → Roadmap → Support** — Nommer la perte → Peindre le gain → Donner la feuille de route → Structurer le soutien.
Usage : conduite du changement à fort impact humain.

## Famille F — Légitimation / candidature

**Pourquoi faire → Pourquoi moi → Pour qui → Pourquoi maintenant** — Justification du projet → Légitimité personnelle → Bénéficiaires/finalité → Opportunité temporelle.
Usage : candidature, prise de poste, défense d'une position personnelle.

**STAR** — Situation → Tâche → Action → Résultat.
Usage : entretien comportemental, démonstration de compétence par l'exemple. Repose sur : les comportements passés prédisent les performances futures.

## Famille G — Confrontation / récit

**Réfutation** — Reformuler l'objection → Valider le ressenti → Apporter preuve/réponse structurée → Renverser l'obstacle en opportunité.
Usage : audience sceptique, gestion d'objection en direct.

**Inductif (storytelling)** — Cas concret → Analyse (« que nous apprend ce cas ? ») → Généralisation/règle → Application/conclusion.
Usage : renforcer l'impact, donner du concret avant la conclusion générale.

**Polyphonique** — Orchestrer plusieurs voix/perspectives convergentes sans qu'aucune ne domine.
Usage : communication interculturelle, sujet à parties prenantes multiples.

**Rampe de lancement** — Chaque argument prépare et appelle le suivant, progression addictive jusqu'au point culminant.
Usage : maintenir une curiosité croissante, montée en intensité.

## Famille H — Classique

**Plan cicéronien (5 parties)** — Exorde (capter la bienveillance) → Narration (exposer les faits) → Division (annoncer le plan) → Confirmation (développer les arguments) → Péroraison (conclure avec force).
Usage : discours académique, juridique, politique formel.
