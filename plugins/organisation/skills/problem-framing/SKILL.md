Ce skill traite tout problème complexe comme une **anomalie** au sein d'un système. L'objectif est d'extraire le **signal**, de diviser les forces via le principe **MECE** et de figer l'espace de résolution.
 
## Étapes
 
1. **Isoler le Signal**
   Extrayez l'observation brute de l'anomalie. Définissez les 4 vecteurs d'identification :
   - L'Entité (le sujet exact).
   - La Topologie (l'espace et l'instant T).
   - La Cinématique (la forme observable de la défaillance).
   - Le Point de Bascule (le déclencheur de la tension).
   Descendez l'échelle causale des "pourquoi" jusqu'aux lois fondamentales (physiques, mécaniques, psychologiques).
   *Critère d'achèvement* : L'anomalie est réduite à une mécanique observable de cause à effet, purifiée de tout biais d'interprétation.
2. **Appliquer le Principe MECE (Mutuellement Exclusif, Collectivement Exhaustif)**
   Divisez les forces du problème en trois dimensions distinctes :
   - Structurelle/Mécanique : Squelette, règles rigides, limites physiques, processus.
   - Agentique/Relationnelle : Acteurs autonomes, comportements, biais, motivations.
   - Environnementale/Contextuelle : Écosystème, pressions exogènes, ressources.
   *Critère d'achèvement* : Les sous-composantes ne se chevauchent pas et couvrent l'intégralité du système.
3. **Mesurer les Vecteurs d'État**
   Pour chaque dimension MECE validée, objectivez la situation :
   - L'État Réel : Mesure factuelle immédiate.
   - La Trajectoire : Dynamique historique (dégradation, stagnation, oscillation).
   - Le **Delta** : L'écart mathématique ou conceptuel avec la norme d'équilibre.
   - Les Frictions : Les points d'usure immédiats.
   - L'**Entropie** : Les conséquences en cascade prévues sans intervention.
   *Critère d'achèvement* : Les 5 vecteurs sont documentés factuellement pour l'ensemble des dimensions.
4. **Verrouiller les Limites**
   Délimitez l'espace strict dans lequel la solution devra exister :
   - La Densité : Le degré d'interdépendance des variables.
   - La Vélocité : La vitesse de rapprochement vers un point d'effondrement.
   - Les Conditions aux Limites : Les frontières infranchissables (lois, temps, budget, énergie).
   *Critère d'achèvement* : Les contraintes incompressibles de résolution sont définies.
5. **Synthétiser le Template Universel**
   Encapsulez le travail de fond (legwork) dans le rendu final pour l'utilisateur, en utilisant le format de référence.
   *Critère d'achèvement* : Les 5 points du Template Universel sont générés et remplis avec précision.
## Référence : Le Template Universel de Problématique
 
Générez ce format exact en sortie, sans le modifier, pour formuler le problème de manière inattaquable :
 
1. **Phénomène Observé** : [Description neutre de l'anomalie de surface]
2. **Le Delta** : Le système se trouve à un état [X], en contradiction avec l'état d'équilibre [Y].
3. **Nœuds Causaux** : Cette tension est le produit de failles : [Structurelles/Mécaniques] et [Agentiques/Relationnelles] au sein d'un écosystème [Environnemental].
4. **Projection** : Sans intervention au point de bascule, le système subira [Entropie/Dégradation en cascade].
5. **Espace de Résolution** : L'intervention devra s'opérer sous des contraintes de [Temps/Ressources/Conditions aux Limites] avec une complexité d'interdépendance de niveau [Faible/Modéré/Critique].
